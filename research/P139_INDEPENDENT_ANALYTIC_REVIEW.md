## 2. Analytic valuations and a strictly positive D coefficient

Fix finite K,m, one real-analytic curve on (-rho,rho), T_0=E, and contraction for nonnegative x<rho.
Complex entries are real-analytic in the real parameter; their conjugates and squared moduli are also real-analytic.
For Y!=R, every path `a_sigma=prod_j T[Y_j,sigma(j)]` contains s=|Y\R| outside-row factors vanishing at zero.
If its germ is not identically zero, analyticity gives finite integer valuation v_sigma>=s>=1.
Write its first nonzero coefficient alpha_sigma, and v_Y=min v_sigma among surviving paths.
Then

    p_D(Y;x)=sum_sigma |a_sigma(x)|²
             =a_Y*x^(2v_Y)*f_Y(x),
    a_Y=sum_(v_sigma=v_Y)|alpha_sigma|²>0,  f_Y(0)=1.

No distinct-path cancellation can remove this D leading coefficient.
The B permanent can cancel, but universal Cauchy gives `p_B(Y;x)<=K!*p_D(Y;x)` pointwise.
CF input and output have factorial1, so no denominator is missing in that comparison.

If all paths have zero germs, choose a neighborhood in which every path vanishes.
There are only K! paths per Y; both B and D are zero throughout their common neighborhood, not merely at x=0.
If D's germ is zero, positivity of the squared-path sum also forces this same situation.
Those zero-germ radii must constrain the final window so that c*kappa also remains in them; the source explicitly includes them.

## 3. The tolerance and common physical radius

Let q=c², f=K!, c=ceil(sqrt(K!+1)); then q>f and c>1.
With the source's tolerance `eta=(q-f)/(2(q+f))`, one has 0<eta<1/2 and

    q*(1-eta)/(1+eta)-f = (q²-f²)/(3q+f) >0.

This eta is a continuity tolerance, not an optical transmission parameter.
For each nonzero D germ choose r_Y>0 so 1-eta<=f_Y(x)<=1+eta on |x|<r_Y.
For 0<kappa<r_Y/c, D(kappa)>0 and

    p_D(Y;c*kappa)/p_D(Y;kappa)
      =c^(2v_Y)*f_Y(c*kappa)/f_Y(kappa)
      >=q*(1-eta)/(1+eta)>K!.

Combining with Cauchy proves strict domination for each nonzero D germ, including when B vanishes by interference.
Take the minimum of rho/c, every nonzero-germ r_Y/c, and every zero-germ neighborhood radius divided by c.
The number of Y is finite, so after any desired strict-endpoint decrease this common kappa0 is positive.
It keeps both settings inside the physical curve domain; there is no evaluation at an inaccessible parameter.
This is an existence argument depending on the fixed curve and finite pool, not a uniform lower bound or an algorithm to find it.
For K2,K3,K4 the safe c values2,3,5 are correct; the dense P137 result remains stronger where its premises hold.
The rational-reflection inverse is nonsingular at zero, analytic nearby and physical for real x by its exact Gram identity.

## 4. Sparse hand and nonanalytic boundary attack

For the stated three-by-three chain H, its characteristic polynomial is lambda*(lambda²-1/2), so ||H||<=1.
Squaring gives B=diag(1/4,1/2). With a=(1+x²/8)^(-1), b=(1+x²/4)^(-1),
the Y={1,2} submatrix is exactly `[[i*x*a/2,b],[0,i*x*b/2]]`.
There is one nonzero assignment, with amplitude `-x²*a*b/4`.
Thus B=D=`x^4/[16*(1+x²/8)²*(1+x²/4)²]`, as asserted.
Here H[2,0]=0, but the retained row1 supplies source0 at order x and outside row2 supplies source1 at order x.
The path valuation2 exceeds the single-replacement count1; it is not a new row generated by H².
The positive-strength F support connects both sources; no support-component equality was assumed.
The ratio at c*x tends to c^4 near zero and c^(-4) at infinity.
This disproves all-strength use of a prescribed stretch, not independent D retuning: same-setting D already equals B in this hand.

For the C-infinity caution, rotate source0 by theta(x)=exp(-1/x²)cos(1/x) toward row2 and keep source1 fixed.
Flatness makes this a smooth isometric curve with T_0=E, but not an analytic one.
At x_n=1/((2n+1)pi), theta(x_n)=-exp(-((2n+1)pi)²), nonzero and of magnitude<1.
At 2*x_n the cosine is zero. Hence B(x_n)=D(x_n)=sin²(theta(x_n))>0, whereas D(2*x_n)=0.
For large n both parameters lie in any prescribed neighborhood.
The K2/c2 near-zero ordering therefore fails for this nonanalytic extension; no universal claim about every possible retuning is justified.
