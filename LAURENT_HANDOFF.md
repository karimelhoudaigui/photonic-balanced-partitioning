# Dossier Laurent — point d'entrée

Pour **Lucy via TGCC**, commencer par **[docs/LUCY_TGCC.md](docs/LUCY_TGCC.md)** : environnement CEA, préparation locale, interrogation des specs, autorisation d'un plan précis, lancement et analyse séparée. Le dernier **[PDF](paper/main.pdf)** et ses **[sources LaTeX](paper/main.tex)** sont versionnés avec les résultats.

Le dossier scientifique détaillé est [docs/LAURENT_HANDOFF.md](docs/LAURENT_HANDOFF.md). Les commandes hors ligne sont dans [qpu/README.md](qpu/README.md) et les données dans le [catalogue des résultats](results/README.md).

La chaîne hors ligne est testée, avec références Fock complètes, trois circuits n4k2, exports Perceval, compilation locale et analyse de comptages synthétiques. L'adaptateur Lucy est testé avec un transport simulé. La compatibilité matérielle, l'accès au backend et les calibrations ne sont pas vérifiés. Aucun QPU n'a été lancé, aucun crédit consommé, et aucun message n'a été envoyé à Laurent.

Lire également [QPU_READINESS](reports/QPU_READINESS.md), [la thèse de l'article](reports/PUBLICATION_THESIS.md) et [le manuscrit PDF](paper/main.pdf). L'ancien handoff est conservé dans l'historique Git ; ses revendications retirées ne doivent pas être réutilisées.
