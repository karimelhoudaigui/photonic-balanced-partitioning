# Open Scientific Questions

## Primary Question
Can an optimized photonic interferometer simultaneously increase P_CF and concentrate probability on optimal bisections?

## Secondary Questions

1. What is the expected P_CF for a random Haar interferometer?
2. Does optimization create statistically significant enrichment in P_success?
3. What is the Pareto frontier between P_CF and P_opt|CF?
4. Can we achieve P_success > 0 for any interferometer?
5. How does P_success scale with graph size?

## Physics Questions

1. What is the analytical expression for E_U[P_CF]?
2. Are there interferometer structures that suppress bunching?
3. Can input state engineering improve P_CF?
4. What are the fundamental limits of collision-free probability?

## Implementation Questions

1. Which optimization objective is most hardware-relevant?
2. How to count physical shots vs. optimization evaluations?
3. What constitutes a fair comparison with penalty methods?
