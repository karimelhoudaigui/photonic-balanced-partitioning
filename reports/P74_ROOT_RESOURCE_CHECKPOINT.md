## What the screen proves

Use N dual-rail logical qubits/N signal photons/2N rails, a properly paid
source and a noncommuting mixer. A graph-cost phase uses graph weights
only; by itself it does not alter uniform Dicke measurement probabilities.
If every credited raw candidate needs at least g monitored successes,
each conditional success probability is <=h, and failures are never
erased/recycled into acceptance, then every per-candidate raw mass is
<=h^g. No gate or shot independence is needed.

For D=binom(N,N/2), D*h^g<=1 makes one uniform feasible classical proposal
dominate raw hit probability on every cost sublevel. The same conditional
bound gives best-recorded-cost stochastic domination after T guaranteed raw
attempts with a common incumbent, including all training attempts. This
is not automatically an equal wall-time, CPU, photon or score-cost theorem.

A STIPULATED edgewise connected implementation with g>=N-1 and h<=1/2
passes this negative screen, strictly for even N>=4. Actual gate count is
a hypothesis, not a compiler lower bound: angle cancellations, global
phases on the feasible code and joint blocks can change it.
