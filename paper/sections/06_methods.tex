\section{Variational Collision-Aware Photonic Optimization}
\label{sec:methods}

\subsection{Clements Mesh Parametrization}

We parametrize the $n$-mode interferometer using the Clements mesh~\cite{clements2016optimal}, a rectangular arrangement of $n(n-1)/2$ beamsplitters and $n$ phase shifters that provides a universal parametrization of $\mathrm{U}(n)$. The mesh has depth $n$ with alternating layers of adjacent two-mode unitaries:
\begin{equation}
U(\boldsymbol{\theta}, \boldsymbol{\phi}) = \prod_{\ell=1}^{n} \prod_{a \in \mathcal{L}_\ell} D_a(\phi_a/2) \, R_{a,a+1}(\theta_a) \, D_a(-\phi_a/2) \cdot \mathrm{diag}(e^{i\phi_1},\dots,e^{i\phi_n}),
\end{equation}
where $\mathcal{L}_\ell$ are the pairs of adjacent modes in layer $\ell$, $R_{a,a+1}(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$ is a beamsplitter, and $D_a(\phi) = \mathrm{diag}(1,\dots,e^{i\phi},\dots,1)$ is a phase shifter. The total number of parameters is $n(n-1) + n = n^2$.

This parametrization is hardware-compatible: each gate maps directly to a phase shifter and a tunable beamsplitter (e.g., Mach-Zehnder interferometer) on photonic chips.

\subsection{Objective Functions}

We evaluate six objectives, all computed from the exact output distribution (no shot noise in training):

\begin{enumerate}
\item \textbf{Physical success (primary):} $P_{\mathrm{success}} = \sum_{\mathbf{n}\in\mathrm{CF}, C(\mathbf{n})=C^*} p(\mathbf{n})$. Maximized directly.
\item \textbf{Collision-free probability:} $P_{\mathrm{CF}} = \sum_{\mathbf{n}\in\mathrm{CF}} p(\mathbf{n})$.
\item \textbf{Conditional optimal probability:} $P_{\mathrm{opt|CF}} = P_{\mathrm{success}} / P_{\mathrm{CF}}$.
\item \textbf{Conditional energy:} $\mathbb{E}[C|\mathrm{CF}] = \sum_{\mathbf{n}\in\mathrm{CF}} p(\mathbf{n}) C(\mathbf{n}) / P_{\mathrm{CF}}$.
\item \textbf{Collision-aware:} $\mathbb{E}[C|\mathrm{CF}] + \mu(1-P_{\mathrm{CF}})$ with $\mu=2.0$.
\item \textbf{Log barrier:} $\mathbb{E}[C|\mathrm{CF}] - \gamma \log(P_{\mathrm{CF}}+\epsilon)$ with $\gamma=1.0$, $\epsilon=10^{-12}$.
\end{enumerate}

The physical success probability $P_{\mathrm{success}}$ is the \textbf{only objective that directly maximizes the hardware metric} (expected shots $= 1/P_{\mathrm{success}}$). The others either ignore $P_{\mathrm{CF}}$ (conditional energy, conditional CVaR) or trade it off heuristically (collision-aware, log barrier).

\subsection{Optimization Procedure}

\begin{algorithm}[H]
\caption{Variational Collision-Aware Optimization}
\label{alg:variational}
\begin{algorithmic}
\STATE \textbf{Input:} Graph $G$, $n$ modes, $k=n/2$ photons, objective $f$, max iterations $T$
\STATE Initialize Clements mesh parameters $\boldsymbol{\theta}^{(0)} \sim \mathcal{N}(0,1)$
\FOR{$t = 1$ to $T$}
    \STATE Compute $U(\boldsymbol{\theta}^{(t-1)})$
    \STATE Compute exact output distribution $p(\mathbf{n}) = |\langle \mathbf{n} | \hat{\Gamma}_k(U) | \psi_{\mathrm{in}} \rangle|^2$ for all $\mathbf{n} \in \mathcal{H}_k$
    \STATE Evaluate objective $f(p)$ using exact distribution
    \STATE Update parameters via COBYLA: $\boldsymbol{\theta}^{(t)} \leftarrow \mathrm{COBYLA\_step}(\boldsymbol{\theta}^{(t-1)}, f)$
\ENDFOR
\STATE \textbf{Return:} Optimized unitary $U(\boldsymbol{\theta}^{(T)})$, final metrics
\end{algorithmic}
\end{algorithm}

Key features:
\begin{itemize}
\item \textbf{Exact distribution training:} No shot noise; the objective is evaluated on the exact output distribution. This isolates the optimization landscape from sampling noise.
\item \textbf{COBYLA optimizer:} Derivative-free, handles bound constraints naturally, robust for noisy objectives. We use 200 iterations (201 distribution evaluations including initial).
\item \textbf{Multiple random restarts:} 3 seeds per graph to assess variance.
\item \textbf{Graph-informed initialization (optional):} Spectral partitioning of the graph Laplacian gives an initial balanced partition; a permutation matrix routing the first $k$ modes to that partition provides a structured starting point.
\end{itemize}

\subsection{Collision-Aware Sampling and Metrics}

After optimization, the circuit is evaluated by sampling from the exact distribution (or on hardware). For a given unitary $U$, we compute:

\begin{itemize}
\item \textbf{Collision-free probability:} $P_{\mathrm{CF}} = \sum_{\mathbf{n}\in\mathrm{CF}} p(\mathbf{n})$.
\item \textbf{Physical success probability:} $P_{\mathrm{success}} = \sum_{\mathbf{n}\in\mathrm{CF}, C(\mathbf{n})=C^*} p(\mathbf{n})$.
\item \textbf{Conditional optimal probability:} $P_{\mathrm{opt|CF}} = P_{\mathrm{success}} / P_{\mathrm{CF}}$.
\item \textbf{Conditional energy:} $\mathbb{E}[C|\mathrm{CF}] = \sum_{\mathbf{n}\in\mathrm{CF}} p(\mathbf{n}) C(\mathbf{n}) / P_{\mathrm{CF}}$.
\item \textbf{Expected shots:} $N_{\mathrm{shots}} = 1 / P_{\mathrm{success}}$ with Wilson 95\% CI.
\end{itemize}

Uncertainty quantification uses the Wilson score interval for binomial proportions, inverted to give confidence intervals on $N_{\mathrm{shots}}$.

\subsection{Baselines for Comparison}

\begin{enumerate}
\item \textbf{Haar-random:} 1000 random unitaries per $(n,k)$, exact distribution evaluated.
\item \textbf{Penalty QUBO (classical product Bernoulli):} $n$ logits, penalized objective with $\lambda=10$, 200 random restarts, exact distribution.
\item \textbf{Distinguishable photons:} Same optimized unitary, evaluated with distinguishable-photon statistics (multinomial routing).
\item \textbf{Uniform feasible:} Uniform sampling over $\binom{n}{k}$ balanced partitions.
\end{enumerate}

All baselines use the same graph instances, same optimal energy $C^*$ (computed by exact enumeration for $n\le 12$), and same evaluation budget (200 exact distribution evaluations for variational, 200 random logit evaluations for penalty).
