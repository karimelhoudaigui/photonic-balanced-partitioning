\section{Conclusion}

We have presented a constraint-preserving photonic quantum optimization approach for balanced graph partitioning. Our key contributions are:

\begin{enumerate}
    \item Fixed-$k$ photon interferometer formulation
    \item Exact constraint preservation via photon number conservation
    \item Comparison with penalty-based QUBO
    \item Validation on small instances
\end{enumerate}

\subsection{Key Findings}

\begin{itemize}
    \item Photon number conservation enforces cardinality constraint exactly
    \item No penalty terms needed, reducing coupling complexity
    \item Collision-free probability is 1.0 in fixed-photon subspace
    \item Optimization required to achieve competitive results
\end{itemize}

\subsection{Future Work}

\begin{enumerate}
    \item Implement interferometer optimization
    \item Add realistic noise model
    \item Run QPU experiments
    \item Scale to larger instances
    \item Compare with advanced classical methods
\end{enumerate}

\subsection{Scientific Contribution}

This work demonstrates that physical conservation laws can replace mathematical penalty terms in constrained optimization, offering a more natural constraint enforcement mechanism.
